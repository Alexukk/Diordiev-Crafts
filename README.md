# 💎 Diordiev Crafts: Handcrafted Accessories E-Commerce V2.0.0

**Live Project:** [http://diordievcrafts.pythonanywhere.com/](http://diordievcrafts.pythonanywhere.com/)

An e-commerce web application developed with Flask, designed to showcase and sell exclusive handcrafted goods and accessories (wooden items, bracelets, candles).
The project includes key features such as a shopping cart, integration with an external API (Telegram Bot for order notifications), an Admin panel, and a robust SQLite database structure.
